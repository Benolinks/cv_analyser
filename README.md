**CV Analyzer** 

A web-based CV analyzing application designed to simplify the process of uploading and managing multiple CV documents for Hr recruiters.

This CV Analyzer provides a simple interface for uploading and managing CV uploads. The initial development focuses on the homepage and multiple-file upload functionality and the next pages will be login, logout and records.

Techstack used here includes **React.js, TypeScript, Tailwind CSS** 

we will include Backend with Laravel and database for records and processing
